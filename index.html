        How this differs from a find-and-replace formatter:
        Reflow tokenizes the input - strings, quoted identifiers, comments,
        operators, parentheses - before deciding where anything goes. That's
        what lets it tell a real CREATE TABLE apart from a comment
        that happens to mention one, break each row of a multi-row
        VALUES list onto its own line, and keep
        SELECT, FROM, and WHERE
        as siblings instead of nesting them deeper and deeper. It's a
        best-effort parser for standard SQL dialects (MySQL, PostgreSQL, SQL
        Server, SQLite) - not a full grammar - so unusual vendor syntax may
        format imperfectly.
      


      

        Nothing you paste leaves your browser. Formatting runs
        entirely in client-side JavaScript - there's no server, no upload, no
        network request. You can paste production schemas or real data and
        reload this file from disk later with the same result.
